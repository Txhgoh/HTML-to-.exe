📦 HTML to EXE Builder Pro (by h63bro) — Описание проекта
HTML to EXE Builder Pro — это компактная, быстрая и стильная среда разработки (мини-IDE) и конструктор приложений в одном флаконе. Программа позволяет превращать обычный веб-код (HTML, CSS, JavaScript) в полноценные автономные исполняемые файлы .exe для операционной системы Windows.

Софт идеально подходит для тех, кто хочет создавать десктопные утилиты, интерактивные учебники, кликеры, визитки или интерфейсы управления, используя привычные и простые веб-технологии вместо сложного системного программирования.

Как это работает «под капотом»:
Приложение объединяет в себе два мощных движка:

Chromium (через PyQt6 WebEngine): отвечает за мгновенный рендеринг и отображение HTML/JS кода в окне предпросмотра. Всё, что работает в обычном браузере (анимации, скрипты, градиенты), точно так же будет работать и внутри конструктора.

PyInstaller: автоматизированный сборщик, который в один клик упаковывает код пользователя и веб-движок в единый бинарный файл .exe, готовый к запуску на любом компьютере без установки Python или сторонних библиотек.

🚀 Что изменилось во второй версии (Pro-версия)
В первой версии был заложен базовый рабочий концепт. Во второй версии приложение превратилось в полноценный и удобный инструмент для постоянного использования.

Вот ключевые нововведения и доработки:

1. 📍 Свободный выбор папки сохранения (Output Directory)
Как было: Раньше готовый файл компилировался глубоко во внутренних временных папках конструктора, и его приходилось искать вручную.

Как стало: Добавлена функция «Выбрать папку...». Теперь ты можешь заранее указать Рабочий стол, флешку или любую другую папку на компьютере, и готовый .exe сразу переместится туда. После сборки программа автоматически откроет Проводник и выделит твой файл.

2. ⚡ Система готовых шаблонов кода (Code Templates)
Как было: Каждый раз при запуске приходилось писать код с нуля или копировать его из текстовых файлов.

Как стало: Внедрен выпадающий список с готовыми пресетами:

Пустой лист (базовая структура HTML5).

Стильная форма авторизации (готовый темный интерфейс с кнопкой и полями ввода).

Мини-сайт портфолио (пример адаптивной разметки под личные проекты).
Шаблон загружается в редактор в один клик.

3. 💾 Умное автосохранение сессии (Session Recovery)
Как было: Если ты случайно закрыл программу, или у тебя выключился компьютер — весь написанный код стирался.

Как стало: Добавлена логика closeEvent. При закрытии конструктор незаметно сохраняет текущий текст в файл last_session.html. При следующем запуске программа автоматически считывает этот файл и возвращает твой код на место.

4. 🎨 Профессиональный Dark Mode дизайн
Интерфейс полностью переведен на глубокие темные тона (#1e1e24), которые снижают нагрузку на глаза при долгой работе.

Поле ввода кода получило моноширинный шрифт Consolas, как в настоящих средах разработки (Visual Studio Code / PyCharm).

Кнопки стали плоскими, получили скругления и интерактивный отклик (меняют цвет при наведении курсора).

5. 🛠 Кастомизация метаданных приложения
Добавлена возможность задавать собственное имя для выходного .exe файла прямо из интерфейса.

Реализована полноценная привязка иконок: теперь можно загрузить свой .ico файл, и он нативно вшьется в ярлык итоговой программы Windows.
